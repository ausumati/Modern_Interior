## Experience
- Orange / white / black brand palette matched to the supplied Dhaka Decor logo.
- Supplied logo is used as a local asset: `assets/dhaka-decor-logo.png`.
- Lenis smooth scrolling.
- GSAP + ScrollTrigger reveal, parallax and 3D motion.
- Portfolio category tabs.
- One subcategory accordion open at a time.
- Responsive mobile navigation.
- 3D hover cards and animated portfolio reveals.
- Contact enquiry form that opens the configured email client.
- SEO metadata, canonical URL, Open Graph tags, robots.txt, sitemap.xml and InteriorDesigner JSON-LD.
